This is a REFERENCE ONLY file — note the ".json.txt" extension, not ".json".
The mod's reload listener only loads real ".json" files, so this one is never
picked up as an actual title. That's on purpose, same trick the old Aurilux
Titles mod used for its own example file.

To add a real title to YOUR server:
  1. Copy everything between the ---- lines below into a new file.
  2. Save it as data/<your_namespace>/titles/<your_title_id>.json
     (a datapack path — the same place loot tables/recipes/etc. live).
     <your_title_id> becomes the id you reference from a Title Scroll's
     grants_title data component (see the README's "Giving out a title"
     section for the /give example).
  3. Fill in the fields for your own title. Delete every line in this
     file that starts with "//" first — real JSON has no comments, this
     reference copy is just annotated for you.
  4. Run /reload in-game (vanilla's own datapack reload command — nothing
     custom needed) and the new title shows up immediately.

----------------------------------------------------------------------------
{
  // Exactly what's shown in the /title GUI once unlocked, and what
  // {tenko_title} resolves to for the NeoEssentials chat bridge if you use
  // it. "&" color codes are supported, e.g. "&6Kitsune" for gold text.
  // REQUIRED.
  "display": "&6Kitsune",

  // Freeform label — "common"/"uncommon"/"rare"/"legendary"/whatever your
  // server wants to call it. Purely cosmetic right now (shown once a player
  // has actually unlocked the title — never leaked for an undiscovered
  // one). OPTIONAL, defaults to "common" if you leave it out entirely.
  "rarity": "rare",

  // A short line shown under the title name once it's unlocked. Totally
  // optional flavor text — leave the field out, or set it to "", if you
  // don't want one.
  "flavor_text": "Outfoxed the impossible.",

  // The color of the player's chat messages while they wear this title,
  // e.g. "&b" or "&#FFD700". Only used by chat mods that read it
  // (Elements: Nexus does). OPTIONAL, leave it out for no change.
  "chat_color": "&6"
}
----------------------------------------------------------------------------

That's the entire schema — four fields, no nesting, only "display" is required.
The mod itself ships with ZERO titles built in; every title on your server,
including Tenko's own, lives in files exactly like this one.
